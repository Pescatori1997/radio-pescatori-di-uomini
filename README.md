# 📻 Radio Pescatori di Uomini

> La piattaforma ufficiale di Radio Pescatori di Uomini.

## Missione

Annunciare Gesù Cristo attraverso una web radio moderna, podcast, studi biblici, testimonianze e contenuti che aiutino le persone ad avvicinarsi al Vangelo.

---

## Obiettivo

Creare una piattaforma semplice, veloce e professionale che permetta di:

- 📻 Ascoltare la diretta
- 🎙 Ascoltare podcast
- 📖 Seguire studi biblici
- ❤️ Leggere testimonianze
- 🙏 Inviare richieste di preghiera
- 🤝 Collaborare con il progetto
